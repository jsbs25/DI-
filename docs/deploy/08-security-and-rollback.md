# 08 — 安全、备份与回滚方案（Phase 2）

- **日期**：2026-11-12
- **范围**：认证/隐私/文件/接口/实时/部署流程；数据保护与回滚策略（设计级）。

## 1. 安全基线

### 1.1 密钥与配置
- 所有密钥（OAuth、AI、LiveKit、SMS/邮件、存储签名等）仅存云端 Secret/环境变量管理；**禁止**提交 `.env`、token、证书私钥。
- 最小权限：R2 桶私有、D1/DO 绑定最小化、API token scope 限制。
- 轮换计划：泄露或人员变更时可轮换且支持旧会话失效策略。

### 1.2 认证与会话
- 保留现有密码哈希/盐验证语义；登录失败锁定与审计延续。
- 生产全站 HTTPS/WSS；Secure/HttpOnly/SameSite 策略按跨域与桌面端需求评估。
- OAuth：state/nonce、防重放、回调 URL 严格白名单；`APP_URL` 与代理头可信配置。
- dev 快捷登录：仅受信任本地开发且显式开关，生产 **FAIL-CLOSED**。

### 1.3 授权与隐私
- 服务端强制鉴权：会话/消息/文件/通话/资料按 owner/member/friend/block/privacy 策略校验（对齐 `privacy.ts`/`privacyPolicy.ts`/store 规则）。
- 防越权：对象级 IDOR 检查、群角色校验、管理操作审计。
- 隐私输出：脱敏 presence、字段级可见性与搜索限制保持一致。

### 1.4 输入与接口安全
- 输入校验与长度限制；参数化查询（D1/SQL）防注入；输出编码防 XSS。
- CSRF：Bearer API + Origin 校验为主；若引入 Cookie 会话需 CSRF token/双提交策略。
- 速率限制：登录/注册/OTP/上传/WS 连接与消息/搜索；WAF/Turnstile 可选加固。
- 上传：MIME+魔数+扩展名白名单、大小限制、病毒扫描（若可用且免费范围内则考虑）、随机化存储键、私有读取鉴权。

### 1.5 实时与通话
- WS：鉴权、Origin、心跳、背压与连接上限。
- WebRTC：信令鉴权；TURN 短期凭据；不记录敏感媒体内容（除非明确需求与合规）。

### 1.6 供应链与合规
- 依赖与许可证审计（含 AGPL 组件如 SearXNG 的部署/网络交互影响评估）；不引入未许可代码。
- 日志脱敏（无密码/令牌/完整隐私内容）。

## 2. 备份策略

| 数据 | 备份方式 | 频率/触发 | 保留 | 验证 |
|---|---|---|---|---|
| `server_data.json` | 离线只读副本 + 校验和 | 迁移前、切换前、重大变更前；运行期按快照策略 | 多版本 | 哈希与抽样还原 |
| `server_data/books/` | 目录快照/R2 版本 | 同上 | 多版本 | 文件数与样本内容 |
| `server_data/uploads/` | 目录快照/R2 版本 | 同上 | 多版本 | 元数据与对象可读 |
| `discovery.db*` | SQLite 备份（一致性快照） | 同上/定期 | 多版本 | 查询一致性 |
| D1/R2（迁移后） | 导出/复制/版本化（按平台能力） | 定期与发布前 | 按配额 | 恢复演练 **NOT TESTED** |

- 备份存储位置与访问权限需单独记录（不入仓库）；加密静态备份（若工具可用）。

## 3. 回滚方案

### 3.1 部署级回滚
- **前端**：Pages 回滚到上一成功构建/版本；保留旧域名指向能力。
- **Workers/DO**：版本化部署与快速回退；配置开关回切。
- **DNS**：保留变更前记录快照，TTL 策略允许快速回退（在用户授权下执行）。

### 3.2 数据级回滚
- 迁移未切换：丢弃 staging，源数据不变。
- 切换后发现错误：停止新写（维护模式）→ 评估差异 → 从备份恢复旧存储或回放补偿（需预设计）→ 切回旧端点/配置。
- **禁止**在回滚中执行破坏性清理；优先保证数据可恢复。

### 3.3 功能级降级
- 外部依赖不可用（SMS/邮件/AI/搜索/LiveKit/TURN）→ 明确 **BLOCKED/UNAVAILABLE** 与用户提示，不伪造成功。
- 实时不可用 → REST 同步降级（限流）；通话不可用 → 仅信令失败提示。

## 4. 变更与审计
- 每阶段：diff 审查、无密钥扫描、测试记录、commit 与推送可追溯。
- 生产变更窗口与通知（如适用）；安全事件响应联系人与流程（待用户定义）。

## 5. 残余风险
- 免费托管平台的数据持久性与备份粒度受限 — **UNVERIFIED**，需在选型落地时补充平台原生能力。
- 多活/跨区一致性超出当前范围；本方案以单事实源与可回滚为优先。
