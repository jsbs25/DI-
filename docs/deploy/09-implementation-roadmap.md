## 详细步骤

### 阶段 3：云端环境准备（免费、测试优先）
- 核实并记录 Workers/Pages/D1/R2/DO（及备选 Turso 等）**当日免费额度**与限制截图/链接。
- 创建测试资源与最小权限 token；配置 CI 预览（不触发付费）。
- **不**改正式 DNS，不导入生产数据。

### 阶段 4：前端部署
- 固化构建命令（`npm run build`）与产物目录；配置 SPA fallback。
- 环境变量：`API_BASE_URL`/WS 端点（按实现策略）；桌面端与 Web 配置分离。
- 验证：路由刷新、`/jupiter/*`、静态资源、移动端；与现有本地 dev 并行不冲突。

### 阶段 5：后端迁移（推荐顺序）
1. **适配层**：健康检查、统一错误格式、CORS、日志与请求 ID。
2. **无状态只读**：公开配置/部分搜索代理（视外部依赖）。
3. **认证与账号**：登录/注册/会话/OAuth 回调（与 APP_URL 对齐）— 高风险回归。
4. **核心业务**：用户/好友/隐私/通知/帖子/内容。
5. **文件**：上传/下载改 R2 抽象；头像与消息附件。
6. **Messenger API**：REST 同步与历史查询对齐 DB。
7. **Calls/AI/Library/Discovery**：按依赖与配额逐步接入。

> 若采用方案 C 轨 1，可先部署“原 Express 后端 + 外置持久化”的过渡形态，再逐模块替换。

### 阶段 6：数据库与文件迁移
- 实现迁移脚本（dry-run、校验、幂等 staging）与回滚导出工具。
- 顺序：users/accounts/sessions/privacy/prefs → 社交图与会话 → messages（分批）→ books/annotations/shelf → uploads 映射 → discovery（PoC 后）→ calls/audit。
- 每批次输出对账报告（计数/哈希/抽样）。

### 阶段 7：实时通信
- M1：加固单实例 WSS（心跳、重连、限流、观测）。
- M2：DO 分片实现、seq/idempotency、增量 sync；压测连接与消息风暴（免费额度内）。
- 多端真实测试矩阵：Web-Web、Web-Electron、离线恢复。

### 阶段 8：视频通话
- 验证 P2P+STUN 可达场景；记录失败网络类型。
- 决策 TURN/LiveKit：若无 $0 可靠方案，保持功能受限声明并不启用虚假中继。
- 群聊与屏幕共享按能力开关。

### 阶段 9：安全检查
- 自动化与手工：鉴权绕过、越权、XSS、注入、上传、CSRF、速率限制、敏感信息泄露。
- 第三方回调与 Webhook 签名校验；密钥轮换演练（可选）。

### 阶段 10：正式上线
- 预发布清单：备份完成、回滚演练、监控告警、支持渠道。
- DNS 与 OAuth 切换按 06 流程；全球可达性实测与报告（含中国大陆限制说明）。
- 发布后 24-72 小时强化观察。

## 依赖与里程碑
- **M1**：Phase 2 批准 + 额度复核完成。
- **M2**：Pages 测试域名稳定 + 前端回归通过。

- **M4**：Messenger 多端实测通过。
- **M5**：正式域名上线与全量测试报告。
