# Third-party notices

## react-browser-components

The browser chrome in `src/components/browser/BrowserFrame.tsx` adapts the Chrome-style browser-frame and tab-layout pattern from [EnhancedJax/react-browser-components](https://github.com/EnhancedJax/react-browser-components), copyright Ashish Kachhadiya. The upstream project describes these components as visual browser frames rather than actual web browsers. EARTH ONE keeps its existing navigation, page rendering, search, bookmarks, reading mode and AI features; this local adaptation uses the project's existing React/Tailwind stack and does not bundle the upstream npm package.
