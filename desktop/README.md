# Desktop prototype files

- `launcher.cjs`: starts the existing local Express/Vite app on loopback and launches Electron.
- `main.cjs`: secure desktop shell, origin-checked IPC, local browser data/session settings and ID-only download-folder validation in Electron `userData`.
- `preload.cjs`: narrow EARTH ONE-only bridge for navigation, local bookmark/history data, opt-in tab-session restore, downloads, session-only site permission decisions/review, popup-created tab synchronization, address-bar focus, and a path-free save-PDF action.
- `browser-engine.cjs`: Chromium `WebContentsView` lifecycle, validated visual tab ordering, one-shot URL-only restore of the most recently closed tab, HTTP(S)-only popup-to-tab routing, active-tab focus, link context-menu hooks, URL checks, navigation state, owned-tab downloads, active-visible-tab print targeting, and in-memory per-tab zoom.
- `browser-shortcuts.cjs`: allowlisted Ctrl/Cmd Browser and page-zoom shortcuts parsed only from Electron's trusted `before-input-event`, including `Ctrl/Cmd+Shift+T`; zoom is clamped to 50–200%, and no renderer IPC command lets remote pages invoke shortcuts.
- `browser-print-pdf.cjs`: main-process-only Chromium PDF export through the native save dialog, same-origin HTTP(S) validation, active-tab revalidation, and atomic local file writes; it does not expose paths or open generated files.
- `browser-popup-security.cjs`: validates popup/context-menu destinations, excludes the EARTH ONE app origin, and requires app confirmation for every webpage popup because Electron does not provide a trustworthy user-gesture signal.
- `browser-permissions.cjs`: in-memory, per-origin permission state for notifications and geolocation; rejects insecure/non-HTTP(S), subframe, inactive-page and unsupported-permission requests, and clears grants on process exit.
- `session-store.cjs`: versioned, atomic, local-only opt-in tab-session store; saves at most 12 HTTP(S) URLs with safe host labels, rejects credential-bearing URLs and clearly sensitive query keys, removes fragments, and preserves ordinary query strings. It never stores browser cookies, page state or form contents; corrupt/oversized files fail closed without overwriting the source.
- `download-manager.cjs`: bounded local-only download history, safe display metadata, progress/cancellation, interrupted-on-restart restoration, and record-only remove/clear; production leaves save-path selection to Electron's dialog.
- `download-store.cjs`: versioned, validated, atomic `userData` store for at most 50 approved download records; corrupt stores fail closed without overwriting the original.
- `test-download-manager.cjs`: synthetic local DownloadItem and temporary-store tests for explicit save approval, restart restore, corrupt-store handling, the 50-record bound, missing-file validation, and record removal without deleting files.
- `test-browser-permissions.cjs`: unit tests for default deny, explicit decisions, secure-origin rules, origin/capability isolation, revocation, timeout, invalidation, and session-only grants.
- `test-browser-print-pdf.cjs`: synthetic tests for trusted-origin and main-frame boundaries, unsupported schemes, inactive-tab rejection, native-dialog cancellation, path validation, renderer-independent paths, and atomic PDF output.
- `test-browser-popups.cjs`: synthetic policy/engine tests for dangerous protocols, malformed and credential-bearing URLs, app-route boundaries, gesture-ambiguous confirmation, context-menu routing, foreground focus, dedicated Browser-session reuse, and no preload/Node inheritance.
- `test-browser-shortcuts.cjs`: unit coverage for Ctrl/Cmd modifiers, tab cycling/index selection, preserved address/find keys, and invalid modifier/key combinations; the Electron integration smoke sends native Chromium input events across synthetic pages.
- `test-browser-tabs.cjs`: main-process tests for exact tab-order validation, visual-order session snapshots, fresh-ID one-shot URL-only restore, sensitive-query omission, fragment stripping, no zoom restoration, forged identity/URL rejection, and safe last-tab replacement.
- `test-browser-connection-status.cjs`: simulated main-frame HTTP/accepted-HTTPS, redirect protocol, per-tab state, subframe exclusion, rejected certificate, neutral load error and recovery tests; the Electron integration suite uses only a temporary loopback self-signed cert for blocked-navigation checks and never trusts it.
- `test-browser-zoom.cjs`: unit coverage for zoom bounds, active-tab-only changes, independent same-origin tab values, last-tab replacement, and Ctrl/Cmd zoom shortcut parsing; the full Electron suite checks real Chromium scaling, app-input/Reader exclusions, cross-origin separation, URL-only session restore, and restart at 100%.
- `test-session-store.cjs`: tests default-off behavior, sensitive-query omission, ordinary-query/fragment handling, invalid URL removal, the 12-tab cap and corrupt/oversized-store protection.
- `test-browser-integration.cjs`: starts isolated `127.0.0.1` fixtures and temporary server/Electron profiles; under Xvfb it verifies real Electron tab dragging/reordering, restore toolbar and shortcut, URL privacy boundaries, popup handling, permissions, restart reset, downloads/sessions, and Chromium PDF output from a local two-page fixture, including cancel and no-network behavior. HTTP(S) requests outside fixture origins are canceled.
